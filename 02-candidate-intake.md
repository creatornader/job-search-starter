# Prompt 2: Build the Candidate Evidence Layer

Use this after the repository audit. Provide the candidate's materials as files or paste them into the conversation.

```text
Using the repository audit and the candidate materials I provide, create or update a private candidate evidence layer. Do not change the original resumes or public profiles. Do not invent facts.

Create a compact source of truth that captures:

- employment history, responsibilities, outcomes, and quantified evidence
- education, certifications, tools, and methods
- work samples, projects, writing, and relevant portfolio links
- target roles, seniority, industries, locations, work authorization, and constraints
- differentiating strengths, credible adjacent experience, and real gaps
- 6 to 10 interview stories with situation, action, result, and reflection
- resume variants and what each one is best for

For every non-obvious claim, point to a source file or mark it “candidate-confirmed.” Flag conflicts, vague dates, missing metrics, or unsupported claims for review instead of resolving them by guesswork.

Keep the candidate's existing visual resume template as the default formatting authority. Create targeted copies later; do not replace the originals.
```

## Candidate input checklist

- Resume(s) in editable and PDF form, if available
- LinkedIn profile/export
- Past application materials and outcomes
- Work samples and portfolio links
- A written target-role brief
- Company watchlist and avoid list
- Compensation, geography, work-authorization, and schedule constraints
