# Prompt 5: Run the First Discovery Cycle

```text
Run the first supervised discovery cycle using the approved candidate profile and discovery configuration. Search the configured employers and broad official ATS sources. Then verify every surviving role on the employer's own careers page.

If Career-Ops is installed, use its configured portal scan and reverse-ATS discovery as the starting point. If it is not installed, use the existing repository's approved discovery mechanism and the same official-source liveness standard. You may use AI Job Search's ranking ideas after discovery, but do not treat its original portal coverage as complete for this candidate's market.

Return no more than ten live roles, ordered by fit. For each role include:

- company, exact title, official URL, source, location, and advertised compensation if present
- why it fits the candidate's actual evidence
- the most meaningful gap or uncertainty
- liveness evidence and date checked
- whether a referral route is worth pursuing before a direct application
- recommended next action: skip, monitor, evaluate, pursue referral, or prepare application

Do not draft application materials yet. Do not include expired, inaccessible, duplicate, or vague recruiter leads as if they are active roles. State search coverage and blind spots plainly.
```

## Review with the candidate

The candidate should choose a small number of roles for full evaluation. A good first pass is usually two to four, not ten.
