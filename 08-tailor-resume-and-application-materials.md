# Prompt 8: Build the Tailored Application Package

Run this after the candidate approves the role and application strategy. Use the verified evidence base, not memory from the conversation alone.

```text
Prepare a complete draft application package for this approved role. Recheck the official posting and gather the application form's exact prompts, required fields, word or character limits, attachment requests, and any additional assignment or writing sample. Mark required, optional, candidate-owned, and unresolved items separately.

Before editing, compare every plausible base resume against the role. Recommend the best starting variant and explain why. Review the finished resume as a whole: headline and subheading, summary, role and project selection, bullet content and order, title and dates, overlaps or gaps, and the career progression it communicates. Decide whether each founder, consulting, or side-project entry helps this role. Do not keep or remove an item only to match a preset template.

Return a concise before-and-after change log. For every material addition or rewritten claim, cite evidence IDs. Explain significant omissions too. Keep the candidate's chosen visual template, typography, spacing, and page conventions unless the candidate approves a change. Do not convert a local prototype, proposal, or private experiment into a shipped-product claim.

Draft every relevant application component:
- tailored resume in the candidate's editable format and final PDF
- cover letter or role-specific interest statement when requested or strategically useful
- an answer to every required and useful optional application question
- responses to supplemental forms, written questions, case prompts, or requested work samples
- links, portfolio selections, and attachment list requested by the employer

For each answer, preserve the exact question and limit, draft within the limit, link factual claims to evidence IDs, and identify anything the candidate must personally decide. Use the candidate's own language and examples. Do not copy blocks of wording from the posting or employer website. Flag conflicting or missing facts rather than filling them in.

Render the editable resume to PDF using the candidate's preferred reliable renderer. Inspect both the PDF's visual layout and text layer, check page count and links, and compare the PDF with the editable document. If the renderer changes layout or strips links, report the problem and fix it before marking the packet ready.

Save the posting snapshot, company and role research, resume variants considered, change log, evidence map, editable resume, PDF, drafts, form inventory, and open questions together in a dated folder in the candidate's private repository. Use templates/application-record-template.md when it fits the existing tracker. Do not submit anything or send outreach.
```

## Candidate review

Show the candidate the resume and every answer that represents them. Explain content choices in context of this company and role, including the career story created by titles, dates, and selected experience. Wait for corrections and approval before final preflight.
